## SECTION 5: TECHNICAL SEO

- **Title Tags:** `[Primary Keyword] | BAVESTA Hospitality Services` (Max 60 chars)
- **Meta Descriptions:** Action-oriented, including primary keyword and USP. E.g., "Looking for premium hotel staffing? BAVESTA offers expert hospitality recruitment, payroll, and consulting services. Request a consultation today." (Max 155 chars)
- **Open Graph / Twitter Cards:** Dynamic generation using `react-helmet-async`. Large preview images (`og:image`) featuring the BAVESTA logo and luxury hospitality imagery.
- **Canonical URLs:** Self-referencing canonicals on all pages to prevent duplicate content issues from URL parameters.
- **Robots.txt:** Allow all bots to crawl `/`, disallow `/admin`, `/private`.
- **Sitemap.xml:** Dynamic generation (if using SSR/SSG like Next.js) or static file updated via build script.
- **Schema Markup:**
  - `Organization`: Home page (Name, Logo, ContactPoint, Social Links).
  - `LocalBusiness`: Contact page (Address, GeoCoordinates, OpeningHours).
  - `Service`: On every service page detailing service type, provider, and area served.
  - `FAQPage`: On service pages to dominate "People Also Ask" snippets in Google.

## SECTION 8: UI / UX STRATEGY

### 8.1 Design Philosophy
The brand must exude luxury, reliability, and enterprise scale. We will use a **Dark + Gold** theme to represent premium service, contrasted with stark whites for high readability on content pages.

### 8.2 Color System
- **Primary Base (Dark):** Navy Blue (`#0B132B`) / Charcoal Black (`#121212`)
- **Primary Accent (Gold):** Champagne Gold (`#D4AF37`) / Metallic Gold (`#C5A059`)
- **Secondary Accent:** Soft Silver (`#E0E0E0`) for borders and dividers.
- **Backgrounds:** Pure White (`#FFFFFF`) for readable sections, Off-White (`#F9F9F9`) for alternate sections.

### 8.3 Typography System
- **Headings (H1-H4):** `Playfair Display` or `Cinzel` (Serif, elegant, luxurious).
- **Body Text:** `Inter` or `Plus Jakarta Sans` (Sans-serif, highly legible, modern).
- **Hierarchy:** Strict adherence to font-weight contrasts. Headings bold, body text regular, kickers/subtitles uppercase with wide letter-spacing.

### 8.4 Component System
- **Buttons:** 
  - Primary: Solid Gold background, Dark Navy text, slight scale transform on hover.
  - Secondary: Transparent background, Gold border, Gold text, fills with Gold on hover.
- **Cards:** Glassmorphism effects over dark backgrounds. Soft drop shadows on light backgrounds. Border radius of `8px` (slightly sharp, professional).
- **Animations:** 
  - `framer-motion` for page transitions (fade-in, slide-up).
  - Reveal animations on scroll for text and images.
  - Parallax effects on hero images to create depth.
- **Mobile Design:** Bottom navigation bar for core actions (Call, WhatsApp, Email). Large, thumb-friendly tap targets. Native-feeling drawer menus.

## SECTION 9: REACT IMPLEMENTATION

Since the requirement asks for the simplest architecture without a backend, we will use a robust static React architecture, optimized heavily.

### 9.1 Folder Structure
```text
src/
├── assets/          # Compressed WebP images, SVGs, Fonts
├── components/      
│   ├── layout/      # Navbar, Footer, Sidebar
│   ├── ui/          # Buttons, Cards, Modals, Inputs
│   ├── seo/         # SEO Helmet component
│   └── sections/    # Hero, Testimonials, ContactForm
├── pages/           # Home, About, ServiceDetail, Blog, Contact
├── routes/          # AppRoutes.jsx with lazy loading
├── styles/          # Tailwind configuration and global CSS
├── data/            # Local JSON files for Services, Team, Blog content
└── utils/           # Analytics tracking, form validators, helpers
```

### 9.2 Architecture & SEO Setup
- **React Helmet Async:** Used to inject dynamic `<title>`, `<meta>`, `<link rel="canonical">`, and `<script type="application/ld+json">` (Schema) into the `<head>` of every route.
- **Lazy Loading:** Use `React.lazy()` and `<Suspense>` for route-based code splitting. This ensures the initial JavaScript bundle is tiny, leading to instant First Contentful Paint (FCP).

### 9.3 Performance & Core Web Vitals Strategy
- **Image Optimization:** ALL images must be converted to modern `.webp` format. Use `loading="lazy"` on all images below the fold. Add explicit `width` and `height` attributes to prevent Cumulative Layout Shift (CLS).
- **Preloading:** Preload critical assets (Hero image, main fonts) in `index.html`.
- **CSS:** Tailwind CSS ensures only used classes are shipped in production, keeping CSS payload under 15kb.

To build an impenetrable SEO moat:
1. **Content Velocity:** Publish 2 high-quality, long-form (1500+ words) blog posts every week answering specific operational questions hotel owners have.
